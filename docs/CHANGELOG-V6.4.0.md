# NOX HAVEN V6.4.0 — Réorganisation pédagogique

## Architecture des ressources
- Bibliothèque : matières puis chapitres, avec uniquement les cours approfondis, leurs objectifs, points-clés, méthodes et références.
- Révisions : espace central réunissant les fiches de révision et les flashcards, classées par matière puis chapitre.
- Entraînement : espace central réunissant quiz/QCM interactifs, exercices corrigés et sujets originaux de type Bac, classés par matière puis chapitre.
- Les notes personnelles restent séparées des fiches pédagogiques du programme.
- Les flashcards de chapitre peuvent être ajoutées à la répétition espacée personnelle sans duplication.

## Interface
- Navigation desktop et dock mobile réorganisés autour des trois espaces pédagogiques.
- Recherche textuelle et filtre par matière dans les espaces Révisions et Entraînement.
- Les ressources manquantes sont indiquées comme indisponibles au lieu d’être remplacées par du contenu générique.

## Contrôles
- Audit programme : 120/120 ressources référencées ; 120/120 structures atteignent les minima éditoriaux.
- Audit pédagogique : 2 405 QCM, 3 600 flashcards et 1 200 exercices ; 0 explication trop brève et 0 flashcard réellement incomplète selon les règles éditoriales affinées de l’audit.
- Les audits sont structurels et ne remplacent pas une validation disciplinaire humaine.
- Build TypeScript/Vite non exécuté dans l’environnement de préparation faute de dépendances npm disponibles.

- Approfondissement de 65 cours parmi les plus courts, avec des sections contextualisées et des explications supplémentaires.
- Contrôle de profondeur : 120/120 cours dépassent 300 mots ; moyenne d’environ 426 mots.
- Enrichissement des 87 explications initialement trop courtes et clarification de cartes-formules dont la brièveté était adaptée au format flashcard.
- Correction d’un exemple placeholder détecté dans le chapitre SES sur le commerce international.
