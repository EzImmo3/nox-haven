# Démarrer NOX HAVEN 7.2.0

Cette archive est une copie de développement distincte de la version publiée.

## Installation locale (Windows PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
```

Ouvre l'adresse locale affichée par Vite dans le terminal.

## Fonctions ajoutées dans ce lot

- Simulateur Bac 2027.
- Atelier Grand oral.
- Urgence contrôle fondée sur les flashcards et les erreurs de l'utilisateur.
- Carnet de formules et méthodes.
- Carnet d'orientation et suivi des formations.
- Recherche rapide globale avec Ctrl+K.
- Accès aux notes personnelles avec Alt+Maj+N.
- Impression / enregistrement PDF depuis le bouton d'impression du bandeau supérieur.

## Données

Les nouveaux espaces sont intégrés à `StudyData`. Les anciennes sauvegardes sont automatiquement complétées avec des collections vides. Les nouveaux contenus sont enregistrés avec le stockage local existant et suivent les sauvegardes et la synchronisation cloud.

Ne remplace pas le dossier de ta version stable et ne publie pas cette archive avant la validation finale de la compilation et des usages sur appareils.
