# StudyFlow V5.0.15 — accès sur PC et téléphone

- Ajout d'un serveur Vite accessible sur le réseau local (`npm run dev:lan`).
- Ajout d'un aperçu de production accessible sur le réseau local (`npm run preview:lan`).
- Ajout de scripts PowerShell qui affichent automatiquement l'adresse à ouvrir sur un téléphone connecté au même Wi-Fi.
- Ajout d'un guide de démarrage, de dépannage réseau et d'explication des limites PWA en HTTP local.
- Mise à jour cohérente du numéro de version dans l'interface, les sauvegardes, le manifeste et le cache du Service Worker.
- Audit de contenu rendu indépendant du numéro de version précis pour faciliter les prochaines mises à jour V5.0.x.

Aucun changement de contenu pédagogique : la bibliothèque reste à 31 ressources sur 120 chapitres (25,8 %).
