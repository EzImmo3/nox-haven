# StudyFlow V5.0.28 — Physique-Chimie

Ajout de quatre ressources : composition d’un système, évolution temporelle, état final et synthèse organique. Chaque ressource comprend cinq sections, 30 fiches, 20 QCM et 10 exercices de méthode. Les exercices dépendant de données expérimentales signalent explicitement la nécessité de fournir un jeu de données.

Référence : programme officiel Éduscol de spécialité physique-chimie de Terminale. Épreuve session 2027 : note de service du 11 septembre 2026, écrit de 3 h 30 et pratique d'une heure pour les candidats scolaires.

Statut éditorial : draft, relecture disciplinaire humaine recommandée.
