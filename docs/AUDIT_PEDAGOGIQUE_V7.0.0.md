## Limites

- Audit lexical et structurel : ne vérifie pas la justesse disciplinaire ni la qualité didactique réelle.
- Les explications de calcul compactes sont acceptées lorsqu’elles indiquent une opération vérifiable ; les formules seules sont distinguées des explications verbales.
- Une relecture humaine reste nécessaire pour valider les notions, les corrections et les attendus du programme.
